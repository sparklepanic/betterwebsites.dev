This is an overview of the main features of the theme.

## theme features (this is a level 2 header)

- full-text rss
- tags
- monospace or sans-serif system fonts
- auto dark and light modes
- multi-author support with author pages
- optional banner images on the top of posts
- optional table of contents
- 88x31 buttons on homepage
- webrings on homepage
- h-card for basic indieweb support
- link previews with fallback image (opengraph)
- image processing with hugo
- float images left or right with text-wrapping
- easily modifiable for making it your own
- specific CSS for printing, with QR codes automatically generated that link to the live page
- sitemap at the bottom of the page that shows all pages on the site
- `a:visited` to keep track of where you've been on the page
- date in ISO8601 format
- default author setting
- {{< emote src="img/emotes/neodog_laptop_notice.png" >}} [neocritter emojis](https://git.gay/gitgay/assets/src/branch/main/public/assets/img/emoji) via shortcode (supply your own)

for a better view of theme, check out [/posts/theme/](/posts/theme)
